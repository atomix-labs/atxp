# `ruff-house`

The house Ruff, a flavor of the collection's `ruff`, as the linter only:
formatting Python is dprint's, through its Ruff plugin in `dprint-house`. Its
defaults, imports at the top of a module, no file left open, and every public
method documented, at `line_width`.

It owns those keys of `ruff.toml`, under `merge`; `target-version` stays the
repository's.
