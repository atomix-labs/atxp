# `rumdl-house`

The house rumdl, a flavor of the collection's `rumdl`: line length is the
formatter's; rules that rustdoc's intra-doc links and code spans trip are off;
headings are checked for title case; and `<details>`, `<summary>`, `<code>` and
`<span>` are the HTML a page may use.

`exclude` and `[MD063] ignore-words` stay the repository's.
